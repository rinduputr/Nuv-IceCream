# Nuvé Ice Cream Website

Website resmi Nuvé Ice Cream — Find Your Happy Flavor.

## SEO Files Included
- `robots.txt` — Mengizinkan crawling + link sitemap
- `sitemap.xml` — Sitemap untuk Google Search Console
- `site.webmanifest` — Web App Manifest
- Favicons (ico, png, apple-touch-icon)
- `og-image.png` — Open Graph image (1200x630)
- Meta tags lengkap + JSON-LD structured data di `index.html`

## Cara Deploy
1. Upload semua file di root ke GitHub (branch main / gh-pages sesuai setup).
2. Pastikan CNAME berisi `rnduu.my.id`
3. Tunggu deploy selesai.
4. Lakukan langkah SEO di panduan (Google Search Console, dll).

Domain: https://rnduu.my.id/
