# Nuvé Café

Website menu cafe. Desain modern minimalis, warna biru, siap deploy ke GitHub Pages.

## Isi halaman

- Beranda
- Tentang cafe
- Menu dengan filter: Kopi, Non-Kopi, Signature, Pastry, Makanan
- Video gallery (carousel YouTube)
- Galeri foto
- Form reservasi / pre-order (demo)

## Deploy GitHub Pages

Upload isi folder ini ke root repository, lalu aktifkan Pages dari branch main.
