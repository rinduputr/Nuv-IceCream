# Revisi Open Graph Nuvé Ice Cream

Revisi ini menambahkan metadata Open Graph dan Twitter Card di `index.html`, serta gambar thumbnail `og-image.png` berukuran 1200 × 630.

## Cara menerapkan
1. Ekstrak ZIP.
2. Unggah/perbarui isi folder repository ke GitHub, pastikan `index.html`, `og-image.png`, dan file website lain berada di root publik yang sama.
3. Tunggu GitHub Pages selesai deploy.
4. Uji `https://rnduu.my.id/og-image.png` dan pastikan gambar dapat dibuka tanpa login.
5. Bagikan ulang `https://rnduu.my.id/`.

WhatsApp dan platform lain bisa menyimpan cache pratinjau lama, jadi thumbnail tidak selalu berubah seketika. Pastikan DNS/domain dan HTTPS sudah aktif.
